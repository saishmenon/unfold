# Why I quit folders

I rebuilt my folders again this weekend. Three hours of filing, zero minutes of writing. Sorting notes into folders feels like work, but nothing gets easier to find.

New rule: one flat list, search first. If I can't find a note by searching, the note needed a better first line.

Folders answer the question "where does this go?" I only ever ask "where did I put that?"

## What replaced them

1. One flat list
2. `Search` before anything else
3. A *few* broad folders, added late

> File less. **Write a better first line.**
